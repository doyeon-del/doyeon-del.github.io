개요

수집된 데이터가 분석과 시각화에 쓰이는 흐름을 확인했습니다

자산운용사의 ETF 마케팅 데이터 플랫폼에서 SQL 기반 품질 점검과 대시보드 오류 원인 추적을 담당했습니다. 수집된 데이터가 분석과 시각화에 사용되는 흐름을 확인하고, 반복적으로 활용할 점검 기준과 운영 문서를 정리했습니다.

데이터 흐름과 담당 지점. 아래 칩이 각 단계에서 맡은 일입니다. 대시보드에서 발견한 빈 값은 적재·수집 단계까지 거슬러 올라가 원인을 확인했습니다.

담당 업무

점검에서 문서화까지 네 가지를 맡았습니다

  1. 적재 데이터 품질 점검

    SQL로 빈 값과 중복, 날짜별·채널별 적재 건수를 확인했습니다. 대시보드의 빈 값 발생 원인을 수집 단계까지 추적하고, 개발운영팀과 크롤러 구조의 수정 방향을 논의해 반영했습니다.

  2. 데이터 명세와 점검 쿼리 표준화

    30여 개 테이블의 컬럼 정의, 타입, 업데이트 주기, 키를 명세서로 정리하고 자주 사용하는 SQL 쿼리를 표준화했습니다.

  3. 불용어 사전 구축

    반복되는 언론사명이 주요 키워드에 포함되는 문제를 확인했습니다. Python 정규식으로 후보를 추출하고 개별 검수·병합해 1만 행 규모의 불용어 사전을 구축했으며, 데이터 사이언티스트가 분석에 활용했습니다.

  4. 운영 절차 문서화

    빈 값 재발 방지 매뉴얼, DB 접속 절차, 데이터 이관 절차를 작성했습니다.

별도 재현 프로젝트

회사 데이터 대신 합성 데이터로 같은 점검을 재현했습니다

회사 데이터 대신 합성 데이터를 사용해 SQL 품질 점검과 불용어 적용 전후의 키워드 변화를 재현했습니다.

데모에 표시한 수치는 합성 데이터에서 계산한 결과이며, 실제 고객사 업무의 성과 수치와는 구분됩니다.
