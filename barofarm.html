소개

유통기한이 임박한 신선식품을 모아 판매하는 직거래 마켓입니다. 판매자는 재고별 폐기 위험과 할인가를 확인하고, 소비자는 마감 임박 상품을 한곳에서 볼 수 있도록 기획했습니다. 커머스 백엔드와 배포 인프라를 단독으로 구현하고, 클라우드 VM에 배포해 HTTPS로 사이트를 운영하고 있습니다.

운영 중인 홈 화면 (barofarm.duckdns.org)

주요 기능

  1. 마감임박 딜 전용 탭 (/deals)

    유통기한이 임박한 상품을 한곳에 모아 소비자에게 노출합니다.

  2. 폐기위험 산출 · 동적 할인

    유통기한 D-day와 재고로 폐기위험(HIGH/MED/LOW)을 평가하고, 위험도에 연동해 할인가가 바뀝니다.

  3. 판매자 폐기 대시보드

    판매자가 자기 재고의 폐기 위험을 미리 확인합니다.

  4. 시세 기반 추천가

    상품 등록 시 KAMIS 소매 시세를 근거로 판매가를 추천하고, 상품 설명은 gpt-4o-mini로 생성합니다.

  5. 회원 관리와 인증

    JWT로 인증하고, 탈퇴한 회원의 토큰은 블랙리스트로 무효화합니다. 비밀번호는 BCrypt로 해시해 저장합니다.

시스템 아키텍처

기술 선택

고민

주문 시점의 가격 확정

동적 할인은 화면에 보이는 가격과 결제 시점 가격이 달라질 수 있습니다. 클라이언트가 보낸 가격을 그대로 믿으면 가격 조작에 노출됩니다.

결정

주문 시 서버가 재계산해 청구

가격 계산 로직을 서버에만 두고, 주문 시점에 서버가 폐기위험·할인율을 다시 계산해 청구합니다. 화면에서 전달한 가격은 결제 금액 계산에 사용하지 않습니다.

고민

거래 데이터가 없는 상태의 위험도 산출

학습에 사용할 실제 거래 데이터가 없어, 유통기한과 재고에 따른 규칙으로 위험도를 산출했습니다.

결정

규칙 기반 엔진 + 합성 데이터 검증

유통기한 D-day와 재고를 규칙 기반으로 평가해 HIGH/MED/LOW를 산출합니다. 행동로그는 seed를 고정한 시뮬레이터로 합성했고, 이 데이터에서 계산한 지표라는 점을 문서에 적었습니다.

고민

탈퇴한 회원의 토큰

JWT는 발급 후 만료 전까지 유효해서, 탈퇴한 회원의 토큰이 남은 유효기간 동안 살아 있는 문제가 있습니다.

결정

블랙리스트로 즉시 무효화

탈퇴 시 토큰을 블랙리스트에 올려 즉시 무효화합니다. 비밀번호는 BCrypt로 저장하도록 바꿨습니다.

고민

시세 기반 추천가의 근거

추천 가격의 근거를 보여주기 위해 가격 산출에 사용할 시세 데이터와 상품 설명 생성 기능을 분리했습니다.

결정

KAMIS 시세 조회와 상품 설명 생성

판매가 추천은 KAMIS 소매 시세를 근거로 하고 등락·단위 주의 문구까지 노출합니다. LLM(gpt-4o-mini)은 상품 설명 생성에만 씁니다.

문제 해결

배포 단계에서 만난 문제들

  1. 배포 도메인 CORS 403

    운영 도메인에서 백엔드 호출이 403으로 막혔습니다. 배포 도메인을 CORS 허용 목록에 추가해 해결했습니다.

  2. HTTPS 전환 후 혼합콘텐츠

    운영 HTTPS 전환 과정에서 혼합콘텐츠 차단이 발생했습니다. Caddy 리버스 프록시 구성을 정리해 전 구간 HTTPS로 통일했습니다.

  3. Docker MySQL 한글 깨짐

    팀 개발환경(Docker Compose)에서 MySQL 한글이 깨지는 문제를 charset 강제 설정으로 해결하고, Docker Compose로 팀 개발 환경을 통일했습니다.

작업을 돌아보며

배포 단계의 문제(CORS, 혼합콘텐츠, 한글 깨짐)는 대부분 로컬과 운영 환경의 차이에서 생겼습니다. 그래서 배포 전에 운영 구성 그대로 로컬에서 띄워 확인하는 순서를 만들었습니다.

남은 과제

  • 무료 VM(메모리 1GB)에서는 이미지를 빌드할 수 없어, 맥에서 빌드한 이미지를 서버로 옮겨 수동으로 배포합니다. 이 과정을 배포 스크립트로 자동화하는 것이 다음 과제입니다.
  • AI 기능이 SSAFY GMS를 거치기 때문에 SSAFY 망 밖의 서버에서는 호출이 막힐 수 있고, 이때는 규칙 기반 문구로 대체됩니다. 외부 API로 바꿔야 운영 서버에서도 안정적으로 동작합니다.
